# VideoCut без рекламы — версия 0.2

Это исходный проект Android-приложения на Kotlin. Он не содержит рекламных SDK, аналитики или сетевых разрешений.

## Что есть в этой версии
- тёмный интерфейс;
- выбор видео через системный файловый диалог;
- встроенный предпросмотр;
- настройка начала и конца фрагмента ползунками;
- экспорт через AndroidX Media3 Transformer;
- сохранение результата в `Movies/VideoCut`;
- GitHub Actions workflow для облачной сборки APK.

## Что ещё не реализовано
Это основа будущего редактора, а не полный функциональный аналог YouCut. Пока нет склейки нескольких роликов, музыки, текстовых слоёв, фильтров, изменения скорости и отдельного кадрирования с выбором пропорций. Качество кодирования также пока не настраивается — переключатель в интерфейсе оставлен как заглушка и будет подключён в следующем этапе.

## Как собрать APK без Android Studio
1. Создай репозиторий на GitHub и загрузи в него всё содержимое архива.
2. Открой вкладку **Actions**.
3. Выбери workflow **Build VideoCut APK**.
4. Нажми **Run workflow** и дождись завершения.
5. Открой успешный запуск workflow и скачай artifact `VideoCut-debug-apk`.
6. Распакуй скачанный artifact — внутри будет `app-debug.apk`.
7. Перед установкой на телефон скачивай APK только из своего репозитория и проверяй, что сборка завершилась успешно.

## Примечания
- Требуются Java 17 и Android SDK 35; workflow устанавливает их в облаке.
- Минимальная версия Android — 8.0 (API 26).
- Сборка пока не проверена запуском Gradle в этом окружении; если облачная сборка обнаружит ошибки, их нужно исправить по журналу GitHub Actions.
